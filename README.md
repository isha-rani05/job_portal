# job_portal
Craigs is a stylish, responsive directory listing template built with HTML, Tailwind CSS, and PHP. It is designed for showcasing local or global services, classifieds, job types, and more. The template includes a dynamic PHP-powered job type form (with both dropdown and radio options) and a full-featured homepage layout.

🧩Key Features:-

🔥 Fully responsive layout using Tailwind CSS

🌐 Modern navigation bar with dropdown menus

🧭 Integrated search section with "What?", "Where?", and "Category?" fields

✅ Two types of job selection forms:

Dropdown selection

Radio button selection styled as toggle options

🧑‍💻 PHP backend to handle form submissions and display user selections

🎨 Font Awesome icons for enhanced UI

🏁 Clean footer and header sections

🎯 Ideal for directories, job boards, classified listings, etc.

🛠 Tech Stack:

HTML5
Tailwind CSS
PHP
Font Awesome

🚀 How to Run
Clone the repository:
git clone https://github.com/yourusername/craigs-directory.git

Place the project in your server directory (e.g., htdocs if using XAMPP).

Start Apache server (XAMPP, WAMP, etc.).

Navigate to http://localhost/craigs-directory/ in your browser.

Fill out the job type form and see the selected option displayed using PHP.
